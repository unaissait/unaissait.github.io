# Unais Sait — Portfolio Website

A dependency-free static portfolio designed for GitHub Pages.

## Deploy

1. Extract this ZIP.
2. Upload **the contents of the extracted folder** to the root of the `unaissait.github.io` repository.
3. Commit and push to the default branch.
4. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, then choose the repository's default branch and `/ (root)`.

No npm install, build command, database or server is required.

## Important files

- `index.html` — all website content
- `styles.css` — visual design and responsive layout
- `script.js` — filters, project-detail modal, theme and mobile navigation
- `assets/` — portrait, preview and design images
- `labs/circuit-listener/` — preserved live physical-computing prototype

## Updating content

Project card summaries are in `index.html`. Detailed project modal text is in the `projects` object near the top of `script.js`.
